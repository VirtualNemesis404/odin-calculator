# Calculator

A basic calculator built using HTML, CSS and JavaScript.

## Overview

A calculator that uses Graphical User Interface to perform calculations on numbers.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Perform basic mathematical operations like add, subtract, multiplication and division.

## Getting Started

### Prerequisites

- A modern web browser
- Git installed on your system

### Installation

- Clone the repository :
    ```bash
    git clone https://github.com/VirtualNemesis404/odin-etch-a-sketch.git
    ````

- Navigate to the project directory :
    ```bash
    cd odin-etch-a-sketch
    ```

- Open index.html in browser.
